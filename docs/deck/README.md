# 开发流程课件（HTML 幻灯片）

24 页，讲一个真实项目从需求到上线、再到用 Git 持续迭代的完整流程。纯 HTML/CSS/JS，无外部依赖，双击即可放映。

- `index.html`：源文件（引用 `assets/` 里的截图）
- `合唱团分谱系统-开发流程.html`：把截图内联后的**单文件版**，发给学生只发这一个文件
- `build.py`：重新生成单文件版（`python build.py`）

## 操作

| 按键 | 作用 |
| --- | --- |
| `←` `→` / 空格 | 翻页 |
| `N` | 显示/隐藏讲稿（每页都有） |
| `F` | 全屏 |
| `P` | 打印 / 导出 PDF（24 页，一页一张） |
| `1`–`9` | 跳到对应页 |

也可以直接点画面右 1/3 下一页、左 1/3 上一页。

## 页面结构

1. 封面 · 2. 全景路线 · 3. 需求拆解 · 4. 输入格式决定自动化 · 5. 需求边界
6. 架构分层 · 7. 数据模型 · 8. 目录结构 · 9. 拆分引擎选型 · 10. 工具与许可
11. 拆分算法 · 12. 声部识别 · 13. 发布与分发 · 14. 前端集成 · 15. 测试数据
16. PDF 与真实语料 · 17. 测试策略 · 18. 成果展示 · 19. 优化方向
20. GitHub 仓库与首次上传 · 21. 分支模型与提交规范 · 22. PR / CI / 发布
23. 复盘 · 24. 练习

每页结尾都有一句「可迁移的经验」，方便学生带走结论而不是记住截图。
